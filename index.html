Tailor this board to a resume

Claude reads the resume, re-scores all companies for that person with extended thinking, rewrites every match note and the header, then saves the result as a switchable profile. It can then rank the whole openings database for that person and search the web for more. For a candidate outside the Salt Lake area it also re-maps the Where filters to their metro and adds a short list of suggested local employers from Claude's own knowledge, marked unverified. The resume itself is never stored.Works from the profile on screen, so no resume is sent. Claude first ranks every opening in the database for that person, then searches employers' own careers sites for openings the database does not have, opens each posting it finds and saves the ones that are open. Either step can be left out. What it finds is kept in this browser only.

The board is a fixed list of employers, so tailoring alone can never show a job at an employer nobody added. These two steps look past it. The first scores every opening in the database for this person. The second has Claude search employers' own careers sites, open each posting it finds, and save the ones that are open. A deep search can run ten minutes or more and cost a few dollars in tokens and search fees. The web search works from a short brief, never from the resume, and what it finds is saved in this browser only. (If an administrator has turned web search off for your organization in the Claude Console, that step fails and says so.)

Import from a spreadsheet
Your own tracker works as it is: a spreadsheet (.xlsx), CSV or TSV with a header row. Columns are matched by name in any order — Company and Job (or Title) are required, and Date, Location and Result are used when present. A Result such as “Denied, experience” becomes a rejected status and is kept as the note; a row dated “not yet” is skipped rather than counted as applied. Or copy the rows in Excel and paste them here.
